## Preview Selection Format

When showing previews to user via AskUserQuestion:

```python
{
  "question": "Which layout style fits your content best?",
  "header": "Layout",
  "options": [
    {
      "label": "Corporate Deck",
      "description": "Professional, balanced, clear hierarchy for business presentations",
      "preview": "[Insert ASCII from above]"
    },
    {
      "label": "Creative Pitch",
      "description": "Bold, dynamic, story-driven for pitches and proposals",
      "preview": "[Insert ASCII from above]"
    },
    {
      "label": "Data Presentation",
      "description": "Chart-focused, metrics-driven for reporting and analysis",
      "preview": "[Insert ASCII from above]"
    }
  ],
  "multiSelect": false
}
```

## Customization

After user selects layout, ask follow-up questions:

- Color emphasis (primary, secondary, or balanced)
- Content density (minimal, balanced, detailed)
- Visual style (modern, classic, playful)
- Special elements needed (timeline, comparison table, quotes)

Use these to refine the selected base layout.
