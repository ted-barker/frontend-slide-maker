# Wise Survey Workshop - Google Slides Implementation Guide

## Setup Instructions

### 1. Create New Google Slides Presentation
- Go to slides.google.com
- Create blank presentation
- Set slide size: Standard (4:3) or Widescreen (16:9)

### 2. Install Fonts
- Go to More fonts in Google Slides
- Add **Inter** font (all weights)
- For final delivery: Export key headlines as PNG images using actual Wise Sans font

### 3. Color Palette Setup
Save these colors in your custom color picker:

```
#163300 - Forest Green (Primary)
#9FE870 - Bright Green (Secondary)
#FFEB69 - Bright Yellow (Accent)
#A0E1E1 - Bright Blue (Info)
#EDC843 - Warning
#A8200D - Error
#0E0F0C - Text Primary
#454745 - Text Secondary
#6A6C6A - Text Tertiary
#FFFFFF - White
#F5F5F5 - Neutral Background
```

## Export Settings for Final Delivery

### For key headlines using Wise Sans:
1. Create text in design tool (Figma, Sketch, etc.) with actual Wise Sans font
2. Export as PNG at 2x resolution
3. Import PNGs into Google Slides
4. Replace Inter text with PNG images

### Recommended PNG exports:
- Slide 1 title
- Slide 24 key takeaway
- Slide 25 closing

### Presentation Settings:
- **Transitions**: None or subtle fade (200ms)
- **Animations**: Only where specified (build lists)
- **Timing**: Manual advance (presenter-driven)

### Accessibility Notes:
- All text meets WCAG AAA contrast requirements
- Minimum text size: 18pt
- Clear visual hierarchy
- No reliance on color alone for meaning
