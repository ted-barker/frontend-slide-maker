## Design Notes

**Color Palette Used:**
- Primary: #163300 (Forest Green)
- Secondary: #9FE870 (Bright Green)
- Accent: #FFEB69 (Bright Yellow)
- Info: #A0E1E1 (Bright Blue)
- Warning: #EDC843
- Text: #0E0F0C, #454745, #6A6C6A
- Background: #FFFFFF, #F5F5F5

**Typography:**
- Headings: Inter Bold, uppercase for titles
- Body: Inter Regular, 18-24px
- Line height: 1.6 for body, 1.1 for headings

**Layout Principles Applied:**
- One key thing per slide
- Bold simple statements
- Build over multiple slides
- Simplified data visualizations
- Circular icon backgrounds (Wise style)
- Full-bleed color backgrounds for dividers

**Visual Assets:**
- Icons: Outlined circular style with brand color backgrounds
- Gradients: Abstract overlapping circular orbs
- Charts: Simplified, highlighting single key points
- Consistent spacing: 8px grid system

**Accessibility:**
- Contrast ratios meet WCAG AAA
- Focus ring: 3px #163300
- Clear hierarchy and readable sizes
